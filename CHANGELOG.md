# Changelog

## 1.1.3

- Renamed to OpLarik: window and tab title, sign-in screen, tray, overlay window, Start menu / desktop
  shortcuts (OpLarik.lnk), Apps & features entry, file properties, exe name (OpLarik.exe), install
  folder (Program Files\OpLarik), power plan name, 2FA issuer, settings export. Internal identifiers
  keep "Larik" (data folders ProgramData/LocalAppData\Larik, scheduled task names, window classes,
  DPAPI entropy, API token header), so settings and undo backups of earlier versions stay valid.
  Settings exported by "Larik" still import.
- Installing removes a pre-1.1.3 install (Larik.lnk shortcuts, the "Larik" Apps & features entry,
  Program Files\Larik\Larik.exe) and re-points the tray task at the new folder.
- Updates: the release repository defaults to 1larik1/oplarik (public) and checking on start is on;
  release assets are now OpLarik.exe and OpLarik.exe.sha256.

## 1.1.2

- Overlay: background, border, labels, values, FPS color, frame-time graph and warning colors follow
  the app theme (one palette per theme); light themes get a light overlay with dark text. The
  settings preview refreshes when the theme changes.
- Themes: the picker is split into Dark (7) and Light (7). New light themes Sky, Lagoon, Mint, Sand,
  Rose, Paper; "Light" is now called Lavender. Light themes are generated by tools/themes_light.py;
  shared light-mode rules use html[data-tone="light"].
- Settings: the Overlay category no longer shows sub-sections.

## 1.1.1

  opened before signing in).
- Animations are always on; the "Animations" switch was removed and the setting is forced on.
- New languages: Spanish, German, French, Japanese, Czech — whole UI, tweak catalog, tray/dialog
  texts and overlay labels (Japanese overlay labels stay English: the overlay font atlas has no CJK;
  the atlas now includes Latin-1/Latin Extended-A). Japanese UI uses Yu Gothic UI / Meiryo.

## 1.1.0

  Games, Larik), categories with sub-sections that scroll to their part, full-text search across all
  settings, a profile header, × / Esc to close. The page behind it stays as it was.

## 1.0.9

- Start games from Larik: a Play button on every game in "Your games" and a Play row on Home
  (up to 6 games, most recently played first: from Larik's own launches and recorded sessions).
- Steam games start with steam://rungameid/<id>, Epic games with
  com.epicgames.launcher://apps/<namespace>:<item>:<app>?action=launch&silent=true (from the Epic
  manifest), VALORANT / League of Legends through RiotClientServices.exe --launch-product=…; other
  games start from their .exe with their folder as the working directory. Games added before 1.0.9
  get their launcher from the Steam / Epic manifests or the Riot folder.
- Games run with the signed-in user's normal rights: launcher links are handed to Explorer, programs
  are started with a copy of Explorer's token (CreateProcessWithTokenW). Only games from Larik's own
  list can be started, and launch strings are validated.
- Game rows show the launcher, when the game was last played and the total time played.
- If Windows doesn't allow starting a game with normal rights (for example the Secondary Logon
  service is disabled), Larik asks before starting it as administrator instead of doing it silently.
  Store games whose launcher is missing get a clear message instead of a game that closes at once.

## 1.0.8

- Game and program pictures from this PC (nothing is downloaded): Steam games use their library
  artwork from Steam\appcache\librarycache (tall capsule, header as fallback; old flat and new
  per-game folder layouts); other games, games added by hand and startup programs show the icon
  extracted from their .exe (64×64 PNG, read as a resource file only; network paths are refused).
  The UI only receives opaque /api/cover/<id> links. Games added before 1.0.8 get their Steam id
  from the Steam app manifests.
- Found games are shown as posters; names wrap to two lines instead of being cut off.
- Disk type: when Windows reports MediaType "Unspecified", Larik asks the drive whether it has a
  seek penalty (IOCTL_STORAGE_QUERY_PROPERTY, as the defragmenter does) and falls back to known
  model names (WDC WD…, ST…DM, Toshiba DT…, Kingston SA400/SUV500, …). SSD-only optimizations now
  require a drive known to be an SSD.
- Memory tip: Intel B/H/Q chipsets of the 100–400 series (and 500-series boards with 10th-gen CPUs,
  H510, H610) lock memory to the CPU's official speed (e.g. i5-10400 on B460: 2666 MT/s). Instead of
  "turn on XMP" Larik explains the limit, or suggests raising memory only up to it. No XMP tip on laptops.
- New tip: Resizable BAR is off (NVIDIA RTX 30/40/50, read from the NVML BAR1 size), with a warning
  when Windows boots in legacy CSM mode.
- New tip: the monitor supports a higher refresh rate than Windows uses (all display modes at the
  current resolution are checked). My PC shows Resizable BAR and the maximum refresh rate, one row
  per monitor (primary first).
- Pictures are read only from local fixed/removable drives: network paths, mapped network drives and
  relative paths are refused before any file access.

## 1.0.7

Main features
- Before / after (Games page): compares two recorded sessions of the same game: average FPS,
  1% and 0.1% low, median, stability (share of seconds within ±15% of the median), FPS dips,
  temperatures and ping, with an FPS chart. It also lists which optimizations, DNS and NVIDIA
  settings were changed between the two sessions. By default it pairs the newest session with
  the newest older session of that game recorded before a change.
- NVIDIA driver settings (Boost page), written through NVAPI driver settings (the global profile
  shown in NVIDIA Control Panel): power management "prefer maximum performance", low latency
  mode On (max pre-rendered frames 1), frame rate limiter (20–1023 FPS), shader cache size
  unlimited, texture filtering quality "high performance". The first original value of each
  setting is saved to nvidia.json; "Restore" puts it back (or the driver default). The uninstaller
  restores them too.
- Automatic game mode (Boost page): the overlay process now also runs when only automatic mode
  is on. A full-screen, non-ignored program that shows frames (or is a known game) for 8 seconds
  counts as a game: Game Boost turns on (marked as automatic) and the overlay is shown. When the
  game process exits, automatic Boost is switched off and the overlay is hidden again. Boost
  started by hand is never switched off automatically. Leftover automatic Boost is ended at the
  next start.

PC health (new page)
- Disk health from Windows Storage reliability counters and the SMART failure prediction:
  temperature, wear, power-on hours, uncorrected errors, with warnings and a dot on the
  Health page when something needs attention.
- GPU driver: installed NVIDIA version (from the Windows driver version) and, on request, the
  newest Game Ready driver from NVIDIA's driver lookup. GeForce 900/10 cards are shown as
  long-term branch.
- Network test: 30 pings each to the router, 1.1.1.1 and 8.8.8.8 (average, jitter, loss), then
  download and upload speed (Cloudflare speed test, 8 s + 6 s) with ping under load, the
  bufferbloat grade (A+ … F) and plain-language advice.
- Scheduled cleanup: weekly Windows task (Task Scheduler, "Larik Cleanup") that runs
  `Larik.exe --clean` and removes the same temporary files as the Boost tool. Day and hour are
  configurable; a missed run happens after the next sign-in. Shader caches are never touched.

Convenience
- Per-game overlay profiles: metrics, position, layout and size per game .exe.
- Settings export / import (JSON): settings, enabled optimizations and NVIDIA settings. The
  account and the update source are never exported. On import you choose whether to turn the listed
  optimizations on.
- Updates from GitHub Releases: set "owner/repo" in Settings › Updates. A release needs the
  assets Larik.exe and Larik.exe.sha256 (tools/package.sh makes both). The download is accepted
  only from GitHub over HTTPS and only if the SHA-256 matches; the running copy and the installed
  copy are replaced (old files are removed on a later start), then Larik restarts. Optional check at
  start, once a day.
- History notes for DNS and NVIDIA changes.
- The overlay and tray processes of an older version are replaced after an update (only after
  checking that the process really is Larik).

Security and fixes
- DLLs are loaded only from System32 (a DLL dropped next to Larik.exe can't be picked up).
- The machine-wide Game Boost lock is now held on one thread, so the app, tray and overlay never
  wait 60 seconds for each other.
- Switching automatic game mode off ends a Boost it started.

## 1.0.6

- "What's new" window: click the version number at the bottom of the sidebar. It also opens once

- Low input lag mode (Boost page): one switch for shorter mouse and keyboard buffers, no mouse

## 1.0.5

Overlay
- Frame-time graph: a strip of the last 60 frames; stutters show as red bars.
- Ping to the game server (ICMP). The server is found from the game's own outgoing traffic
  (Windows network event tracing, nothing is injected). Servers that ignore ping show a dash.
- Warnings when the GPU or CPU overheats (GPU ≥ 85 °C, CPU ≥ 90 °C) or lowers its clocks under load
  (NVIDIA thermal/power-brake slowdown reasons; CPU running far below base clock).
- Game session recording: one CSV row per second (FPS, 1% low, frame time, GPU/CPU load and
  temperature, GPU clock and power, RAM, ping, warnings) in %LOCALAPPDATA%\Larik\Sessions, and a
  summary after each game on the Games page.

New tools
- Tray icon (Settings › Tray icon): open Larik, Game Boost on/off, show/hide overlay; notification
  with the game summary. Optional start with Windows.
- Startup page: every program that starts with Windows, with switches. Uses the same flag as
  Task Manager, so nothing is deleted and everything can be switched back.
- Fastest DNS (Boost page): measures Cloudflare, Google, Quad9, OpenDNS and your current DNS from your
  connection and switches to the one you pick; "Restore original DNS" puts the old settings back.
- Clear shader cache (Boost page): DirectX, NVIDIA, AMD and Intel shader caches.

New optimizations (8, all reversible)
- Keep Windows core in RAM, Disable Fault Tolerant Heap, No Game Bar pop-ups in games,
  Don't lower game sound during calls, Turn on Storage Sense, Disable search highlights,
  Hide recent files in Explorer, Faster opening of large folders.

Internal
- Game Boost state moved from state.json to its own boost.json so the app and the tray can share it.

## 1.0.2

- New: Larik account (optional, stored only on this PC).
  - Sign-in screen with password every time Larik opens; Larik locks again when its window closes,
    after optional inactivity (5 / 15 / 30 min) or with "Lock now".
  - Profile photo with crop and zoom, editable name, password change.
  - Two-step verification with an authenticator app (Google Authenticator, Microsoft Authenticator…):
    QR code setup, 6-digit codes, replay protection.
  - Recovery key (shown once) to reset a forgotten password.
  - Protection against guessing: after 5 wrong attempts a waiting period starts (30 s, growing to 15 min).
  - Password stored as a PBKDF2-SHA256 hash; account folder readable only by administrators;
    two-step secret encrypted with Windows DPAPI.
- Overlay fixes from code review: GDI leak when the overlay changes size, overlay no longer exits on a
  transient settings read error, non-elevated overlay is replaced by an elevated one, out-of-order FPS
  timestamps, DXGI test presents ignored, more robust single-instance check.
